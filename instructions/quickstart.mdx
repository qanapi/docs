## Welcome to Qanapi

To get started with the Qanapi Encryption API, you will need a few things.

1. An account at https://qanapi.cloud.  Sign up is free.
2. Go to the "Configurations" > "Encryptions"
3. Click "Add Encryption"
    1. Name it whatever you prefer and select your algorithm of choice
    2. Click "Create Config"
4. Go to "Karst_Gorge" > "API Keys"
5. Click "Create New Key"
    1. Select the user, the configs to use and the permissions it can use.
    2. Click "Create Key"
    3. Copy the key that is displayed.  It will never be displayed again.
6. That's it.  With that API Key you can begin using the API routes.
